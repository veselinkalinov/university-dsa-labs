Изисквания: Python 3 с tkinter/Tcl/Tk за графичната демонстрация.
Не са нужни външни Python пакети. Програмите са проверени с Python 3.12.14.

Стартирайте командите в папката с разархивираните файлове:

1. python tree_depth.py
   Резултат: Дълбочина по брой възли: 4
   Дървото се задава чрез Node, left и right в build_example().
   Празното дърво се представя с None. Мярката е по брой възли.

2. python monte_carlo_pi.py
   За seed=42 се получават:
   N=100     K=78     pi≈3.120000
   N=1000    K=782    pi≈3.128000
   N=10000   K=7815   pi≈3.126000
   N=100000  K=78432  pi≈3.137280
   math.pi служи само за сравнение с оценката.

3. python monte_carlo_visual.py
   „Стъпка +100“ добавя сто точки.
   „Автоматично“ пуска обновяването; „Пауза“ го спира.
   „Ново изпълнение“ изчиства фигурата и започва със същия seed=42.
   За нова случайна последователност сменете 42 в random.Random(42).
   Лимитът е 10 000 точки. Очакваният краен брой попадения е 7 815.
   Проверка за наличен графичен модул: python -m tkinter

При проблем с кирилицата в терминала добавете -X utf8:
python -X utf8 tree_depth.py
